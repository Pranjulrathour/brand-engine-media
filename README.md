# brand-engine-media

Public, static image hosting for Pranjul Rathour's Instagram/Threads/Facebook carousel posts.
Generated by [brand-engine](https://github.com/Pranjulrathour/brand-engine) (private) — this repo
holds only the rendered slide images, nothing else (no scheduling data, no content strategy).

Images are fetched directly by Meta's servers (Instagram, Threads, Facebook all require a public
https:// URL for each image in a post) via:

    https://raw.githubusercontent.com/Pranjulrathour/brand-engine-media/main/carousels/<slug>/<NN>.jpg
